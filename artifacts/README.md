# Artifacts

This directory contains files used by the HPC DevOps lab.

## Loaded files

- `debs/`: Slurm 26.11.0 release candidate Debian packages for the cluster nodes and services.
- `images/`: container image archives used by the lab.
- `images/metrics-gateway.tar`: metrics gateway image archive.

These files are local build/runtime artifacts and are not source code.
